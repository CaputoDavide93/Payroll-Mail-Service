❓ How to use Payroll Mail Service

Two things this app does:
  1. 📨 Campaigns — send the same email (with one optional attachment) to a list of people.
  2. 📋 Payslips — send each employee their own PDF, locked with their NI number as the password.

Do Step 1 (Settings) once. Then use Campaigns or Payslips whenever you need.

① First-time setup — do this once

1
Open ⚙️ Settings (top-right) and connect your email

You need a Gmail/Workspace App Password — not your normal login password.

  1. Go to myaccount.google.com → Security → turn on 2-Step Verification (required).
  2. Search "App passwords" → create one called "Payroll Mail".
  3. Copy the 16-character code → paste it into the App password box in Settings.
  4. Fill in your Gmail address, From name, and From address.
  5. Click Save settings, then type your own email in Test email and click Send test.
✅ If the test email arrives, you're ready. If not, re-check the App Password (no spaces).
2
(Optional) Add your Anthropic API key — for smarter payslip matching

In ⚙️ Settings → Anthropic API key, paste a key that starts with sk-ant-. This turns on AI matching and the pre-flight safety check on the Payslips page.

Without a key, payslips still work — the app matches names to files automatically (just without the AI double-check).

📨 Sending a normal campaign

1
Prepare a recipients CSV

Make a spreadsheet and export it as .csv. It needs an email column. A name column is recommended for the greeting.

email, name, department
sarah@company.com, Sarah, Finance
john@company.com, John, Engineering
2
Fill in the “New send” form on the Campaigns page
  • Subject / Body — type {name} (or any CSV column) to personalise, e.g. “Hi {name},”.
  • Recipients CSV — upload the file from step 1.
  • Attachment — optional; the same file goes to everyone.
  • Batch size / pause — leave the defaults (10 every 60s) if unsure.

Click Create & send. You can close the tab — sending continues on the server.

📋 Sending payslips (each person gets their own)

1
Get your two files ready
  • An Excel file (.xlsx/.xls/.csv) with columns: EENo, FullName, NI No, Email Address.
  • A ZIP file containing all the payslip PDFs. Name each PDF with the person's name (e.g. Sarah Jones 25-26.pdf) so it can be matched.
The NI No becomes each PDF's password. Double-check it's correct in your Excel.
2
Upload & Prepare

On the 📋 Payslips page, upload the Excel and the ZIP, then click Prepare payslips. A progress bar shows it extracting and matching. (Watch live detail on the 📜 Logs page.)

3
Review & fix the matches — nothing is sent yet

A table appears showing each employee and the PDF matched to them, with a confidence badge:

  • Green/High — the full name is in the file name. Good.
  • Amber — a weaker match. Glance at it.
  • Red — no file, or needs attention. Fix it.

Use the dropdown in each row to pick the correct PDF, or Remove anyone you don't want to send to.

Check this table carefully — it's your last chance before the PDFs are locked. The same file can't be sent to two people.
4
Approve & Protect

When the table looks right, click Approve & Protect. Only now are the PDFs locked with each NI number. Any failures are listed underneath.

5
(Optional) Pre-flight check, then send

If you added an Anthropic key, click Run AI pre-flight check for a second opinion on the matches. Then click Set up email, write the message, and Send — each person receives only their own payslip.

6
Clean up when done

In Server data at the bottom of the Payslips page, click Delete on the run (or Delete all data) to remove PDFs and personal data from the server.

Unapproved uploads are deleted automatically after 1 hour.

📜 Watching what's happening

The 📜 Logs page shows live activity — uploads, matching, protection, sends, and any errors — colour-coded. Use it if something seems stuck or to confirm a send is going out.

🛟 If something goes wrong

  • Test email won't send — re-check the App Password in Settings (16 chars, no spaces).
  • Pre-flight says “API key rejected (401)” — re-paste your Anthropic key in Settings (no extra spaces), or generate a new one.
  • The review table didn't appear — refresh the page with Cmd/Ctrl+Shift+R.
  • “No valid PDF files in the ZIP” — make sure the ZIP contains PDFs named with the employees' names.
