How to use Payroll Mail Service

1
Set up your Gmail account

Click ⚙️ Settings in the top-right corner. You need a Gmail App Password — not your normal password.

  1. Go to myaccount.google.com → Security → 2-Step Verification (must be on)
  2. Search for "App passwords" → create one named "Payroll Mail"
  3. Copy the 16-character code and paste it into the App Password field
  4. Fill in your Gmail address and click Save settings
  5. Use Send test to verify everything works before your first real send
2
Prepare your recipients CSV

Create a spreadsheet (Excel or Google Sheets) and export it as .csv. It must have:

  • email column — recipient's email address required
  • name column — used in the greeting (e.g. "Hi Sarah,") recommended
  • Any extra columns (e.g. department, salary) can be used as placeholders too
email, name, department
sarah@company.com, Sarah, Finance
john@company.com, John, Engineering
3
Create a send

Fill in the New send form at the top of the page:

  • Campaign name — for your reference only (e.g. "June payslips")
  • Subject — use {name} to personalise (e.g. "Your June payslip, {name}")
  • Email body — write your message; use {name} or any CSV column name in curly braces
  • Recipients CSV — upload the file you prepared in step 2
  • Attachment — upload the PDF (or other file) to send to everyone
  • Batch size — how many emails to send at once (10 is safe for Gmail)
  • Seconds between batches — pause between groups (60s keeps Gmail happy)

Click Create & send. You can close this browser tab — sending continues on the server.

4
Monitor progress

Scroll down to the Sends section. Each send shows a progress bar and counts for sent / pending / failed. The page auto-refreshes every few seconds.

  • Pause — temporarily stop sending (resumes from where it left off)
  • Resume — continue a paused send
  • Stop — cancel the send permanently (remaining recipients won't receive anything)
  • Retry failed — re-queue any recipients that failed (e.g. bad address)
  • Send preview — send yourself a real copy of the email before the full blast
5
Tips & limits
  • Free Gmail accounts: ~500 emails/day. Google Workspace: ~2 000/day
  • The daily limit resets on a rolling 24-hour basis, not at midnight
  • If sending stops unexpectedly, restart the server — it will pick up exactly where it left off with no duplicates
  • Attachments are shared: the same file goes to every recipient
  • Use the Schedule start field to send overnight or at the weekend
